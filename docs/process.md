# Team process

Started from the small squad team setup on 2026-11-26.
Last revisited: 2026-11-26.

## CI

TELUS Digital default (sensible-defaults v2.1.0), except the scheduled drift tier is left out: the coding-session and pull-request tiers run on every change, and the deployment tier runs on merge.

## Branching

TELUS Digital default (sensible-defaults v2.1.0)

## Releases

TELUS Digital default (sensible-defaults v2.1.0), except the team deploys on every merge to trunk instead of cutting a release.

## Docs

TELUS Digital default (sensible-defaults v2.1.0)

## Design intake

Designs are shared as a link in the issue, with a short written brief above the link that says what the change must do.
